MarkSync

Settings

Backup & restore

Export your current bookmarks to an unencrypted file, or restore them from a previous backup. Restoring replaces your current bookmarks.

Conflict recovery

Use these only when sync is stuck in a conflict. Force pull discards this device's bookmarks and replaces them with the server copy. Force push overwrites the server with this device's bookmarks. Both bypass the usual conflict check.

Debug log

Activity from the popup, the settings page and background sync, useful for troubleshooting. The log rotates daily: the last 7 days are kept, older days are dropped automatically. Passwords are never recorded, and bookmarks appear only as counts.
