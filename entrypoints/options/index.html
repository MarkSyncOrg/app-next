Conflict recovery

Use these only when sync is stuck in a conflict. Force pull discards this device's bookmarks and replaces them with the server copy. Force push overwrites the server with this device's bookmarks. Both bypass the usual conflict check, but not the sync direction: the one that would send or receive against it is unavailable.

Debug log

Last 7 days of activity, useful for troubleshooting. Passwords are never recorded; bookmarks appear only as counts.
